# MTSS_Possenti_Antoniazzo

## Roman Number Converter

Progetto di Metodi e Tecnologie per lo sviluppo Software di Possenti Giovanni e Cristiano Antoniazzo
Il programma converte un numero intero tra 1 e 1000 in un numero romano.
